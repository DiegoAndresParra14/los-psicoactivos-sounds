# 🎵 MusicStream – Digital Music Store

### MusicStream es una tienda digital de música donde los usuarios pueden explorar álbumes, reproducir canciones, agregarlas al carrito y completar una compra.
### El proyecto simula el flujo completo de una plataforma de compra de música digital, incluyendo un reproductor individual para cada canción.

### Este proyecto fue desarrollado como práctica de HTML y CSS modular, con una estructura organizada y reutilizable.

# 📸 Vista general
## 🏪 Storefront (Home)

### Aquí el usuario puede explorar los álbumes disponibles en la tienda.

## Características:

### Visualización de álbumes
### Cards con portada, artista y precio
### Acceso al detalle del álbum
### Navegación principal del sitio
